How to check for noindex in meta tags and the X-Robots-Tag header

noindex can come from three places, and the last one never shows in the page source:

  • <meta name="robots" content="noindex"> applies to all crawlers.
  • <meta name="googlebot" content="noindex"> applies to Google only.
  • The HTTP header X-Robots-Tag: noindex, or a bot-scoped value such as X-Robots-Tag: googlebot: noindex, set by the server, CDN or framework.

none means the same as noindex, nofollow.

With curl

curl -sI https://example.com/page | grep -i '^x-robots-tag'
curl -s https://example.com/page | grep -io '<meta[^>]*robots[^>]*>'

For many URLs

node indexability-check.mjs https://example.com/ https://example.com/pricing
node indexability-check.mjs --sitemap https://example.com/sitemap.xml

The free checker reports every noindex source per URL, applies bot-scoped headers correctly (bingbot: noindex doesn't affect Googlebot), and checks robots.txt and canonicals too. One caveat: a noindex added by JavaScript after page load isn't visible without rendering.
